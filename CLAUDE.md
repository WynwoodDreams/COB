# Notes for coding agents

This repo is one of three sites in one workforce ecosystem (COB, BuildersBench, ResumeCanvas).
Read `ECOSYSTEM.md` before starting any work: it holds the owner's vision, the cross-site
handoff contract, and the roadmap. When your change adds or alters a cross-site link, update
the contract and roadmap tables there, and make the same edit to `ECOSYSTEM.md` in the other
two repos so the copies stay identical.

The README is the reference for how this site itself works.
